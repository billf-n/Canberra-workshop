# Event Services Request Form

A multi-step React form for collecting event service requests with a beautiful UI and smooth animations.

## Features

- 8-step form with sliding animations
- Progress bar and step counter
- Question-style labels
- Responsive design
- Yellow-brown color scheme
- CSS variables for easy theming

## Getting Started

### Install dependencies
```bash
npm install
```

### Run development server
```bash
npm run dev
```

### Build for production
```bash
npm run build
```

### Preview production build
```bash
npm run preview
```

## Form Steps

1. Event Type - Select event category with optional details
2. Event Date - Choose event date
3. Guest Count - Enter expected number of guests
4. Services - Select required services (catering, photography, etc.)
5. Additional Info - Optional event details
6. Name - Contact name
7. Email - Contact email
8. Phone - Contact phone (optional)

## Tech Stack

- React 18
- Vite
- CSS Variables
- Modern JavaScript (ES6+)
